# Проверка релиза Robot V8.5 + Web V8.7

Подготовлено 13 сентября 2026 года.

## Исправленные случаи

- Отменённая заявка 289503148 больше не должна удерживать старый pending-plan:
  сначала проверяется финальный статус исторического ордера. Частично
  исполненный или неоднозначный ордер не считается просто отменённым.
- Если поиск сделок по ticket возвращает ошибку, используется запрос по датам
  и точный локальный фильтр order. None остаётся ошибкой, а не пустой историей.
  Эти варианты запросов описаны в [документации MetaQuotes](https://www.mql5.com/en/docs/python_metatrader5/mt5historydealsget_py).
- Ошибка исполнения блокирует новые заявки, но H1-анализ и архив продолжаются.
  Сохраняются срок pending в одну H1 и интервал повторов после ошибки.
- При открытой позиции продолжаются M15 Scout и H1 POSITION_REVIEW.
- Стоп проверяется по экстремуму предыдущей завершённой волны. Произвольный
  ATR/spread-запас удалён; уже установленный SL не расширяется. TP проверяется
  по исходным свечным координатам и допустимым проекциям Fibonacci.
- FVG формируется по трём закрытым свечам: неперекрытый тенями первой и третьей
  участок внутри тела средней направленной свечи. Python задаёт границы,
  Claude отбирает значимые кандидаты. D1/H4/H1 доступны для анализа, M15 — при
  активном H1-сценарии или позиции, M5 FVG отключён.
- Частичный возврат к 50% помечается отдельно. Это не полное заполнение.
  Рисуется оставшаяся часть; полностью перекрытая зона исчезает, в том числе
  по свежему снимку свечей без ожидания следующего FULL. Это правило продукта,
  а не утверждение о гарантированной прогнозной силе FVG.
- Убран переключатель профессионального режима. Объяснения открываются по
  точкам сценариев/FVG/событий; дальние объекты не сплющивают свечи.
- Веб показывает свежий POSITION_REVIEW, отдельный статус торговли и отдельные
  показатели: открытый P/L со свопом, изменение баланса, изменение Equity за день.
- Publisher защищён от повторного запуска другим экземпляром новой версии.

## Границы проверки

Тесты робота использовали имитации MT5 и Claude. Реальные ордера и оплачиваемые
запросы не выполнялись. Рабочие GitHub-репозитории и серверы не изменялись.
Для отрисовки использован настоящий Canvas с имитацией DOM; полный браузерный
прогон недоступен, поскольку загрузка Chromium завершилась сетевым тайм-аутом.
После установки нужно проверить реальное подключение MT5, приём пакета вебом,
и следующий анализ по журналу. Это проверка конкретных регрессий, а не
гарантия отсутствия всех ошибок или прибыльности торговой стратегии.

и `waveframe_web_v8_6`; VERSION внутри кода — 8.5.0 и 8.7.0.
