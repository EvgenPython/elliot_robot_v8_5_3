# WaveFrame Robot V8.5.2

Текущий релиз добавляет stateful end-to-end проверку market/pending/SL/TP,
устраняет потерю ENTRY_CHECK-триггера, чинит MT5 history reconciliation,
добавляет промежуточный M30 decision clock и устойчивое восстановление ответа
Claude после refusal/обрыва. Перед установкой
обязательно выполните `verify_release.py`; подробности — в
`RELEASE_CHECKS_V8_5_2_RU.md`.

Windows-робот для MT5 с многоуровневым анализом Claude, защищённым исполнением
и односторонней публикацией данных в WaveFrame Web.

## Рабочая иерархия

- `D1` — стратегический фон и старшая волновая карта.
- `H4` — родительская структура, уровни, фигуры и сценарий.
- `H1` — структурный владелец торговой идеи и часовой decision clock.
- `M30` — один дополнительный decision clock в `xx:30`, без подтверждения по
  незакрытой H1.
- `M15` — дочерние волны текущей H1-волны и подтверждение входа.
- `M5` — только микроуточнение закрытой свечой; самостоятельной идеи не создаёт.

При открытой позиции анализ не останавливается: каждая закрытая M15 проходит
Scout, существенное событие M15 вызывает глубокий review, а каждая новая H1 —
обязательный глубокий `POSITION_REVIEW`.

Когда позиции нет, каждая новая закрытая H1 теперь обязательно доходит до
торгового решения. В 08:00 FP строится полная D1/H4/H1 карта. В остальные
часы дешёвый Scout решает, нужна ли перестройка карты; если нет, Sonnet 5 всё
равно выполняет отдельный `H1_DECISION_REFRESH` по свежим H1/M30/M15/M5. Поэтому
`SCOUT_NO_FULL` больше не может незаметно оставить час без проверки входа.
Дополнительно в середине часа закрытая M30 повторно проверяет вход по той же
валидированной D1/H4/H1-карте.

## Безопасность исполнения

- Ошибка reconciliation, SEND_INTENT, дневной базы или разрешения терминала
  блокирует отправку нового ордера, но не останавливает H1-анализ и архив.
- Отменённый/истёкший/rejected pending определяется по истории MT5 до поиска
  сделок; при несовместимости ticket-вызова применяется точный date-range
  fallback.
- Один runner и один publisher на инструмент защищены межпроцессными lock.
- Все Claude Messages-вызовы также сериализованы отдельным межпроцессным lock:
  второй процесс не может создать параллельный платный запрос.
- `refusal`, `max_tokens`, оборванный JSON и временная API-ошибка не считаются
  анализом. Один frozen payload повторяется последовательно; отказ получает
  нейтральный recovery prompt, а H1 не помечается обработанной без валидного
  Structured JSON.
- Claude не вызывает MT5. Координаты и торговые изменения повторно проверяет
  Python.
- Сопровождение не открывает, не доливает, не переворачивает и автоматически
  не закрывает позицию; разрешено только безопасно подтянуть SL и пересчитать TP.
- Стоп никогда не расширяется. Он ставится ровно на один минимальный ценовой
  шаг за экстремум завершённой предыдущей волны, кроме большей обязательной
  минимальной дистанции брокера.

## FVG / имбаланс

Python ищет трёхсвечный wick-gap только внутри реального тела средней
импульсной свечи. FVG используются только на D1/H4/H1; M30/M15/M5 отключены,
чтобы младший шум не забивал график. Claude может выбрать только точный
Python-кандидат. Рисуется неперекрытый остаток; касание исходной середины
50% помечается как частичное перекрытие. Полностью заполненные зоны
удаляются и остаются лишь в истории. Частичная зона сохраняется только
при подтверждённой Claude актуальности.

## Проверка без ордеров

```powershell
.\.venv\Scripts\python.exe -X utf8 .\run_tests.py
.\.venv\Scripts\python.exe -X utf8 .\check_trading_ready.py
.\.venv\Scripts\python.exe -X utf8 .\show_trade_funnel.py --days 7
```

`run_tests.py` запрещает сеть и немокированные операции MT5. Подробные JSONL
логи находятся в `logs/events`, точные обезличенные API request/response — в
`logs/api`. Команда `export_diagnostics.py` собирает архив и удаляет ключи и
пароли.

По умолчанию релиз реально торгует только на MT5-счёте режима `DEMO`:
`trading_enabled=true`, `allowed_account_modes=["DEMO"]`. Это не симуляция
ордера: после сигналов и всех проверок вызывается настоящий `mt5.order_send()`
в подключённом DEMO-терминале. REAL требует отдельного явного изменения.

Полная установка: `INSTALL_WINDOWS_V8_5_2_RU.md`.
