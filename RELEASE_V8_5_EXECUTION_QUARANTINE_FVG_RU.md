# WaveFrame Robot V8.5 — непрерывный анализ и строгий FVG

## Исправлен корневой сбой V8.4

В инциденте с заявкой `289503148` MT5 уже показывал отменённый исторический
ордер, но робот продолжал считать его ожидающим. Вызов
`history_deals_get(ticket=...)` возвращал `Invalid params`, после чего старый
fail-closed блокировал не только исполнение, но и новые H1-анализы.

V8.5 сначала проверяет финальный статус исторического ордера. Для истории
сделок предусмотрен второй запрос по диапазону дат с локальным точным фильтром
по `deal.order`. Ошибка исполнения переводится в execution quarantine:
`order_send` запрещён, однако новый H1 продолжает Scout/FULL, архивируется и
публикуется. Одна H1 обрабатывается один раз, а после ошибки повторяется не
чаще чем через установленный интервал.

## Анализ и сопровождение

- D1/H4/H1 формируют полную карту рынка.
- H1 принимает решение о входе; H1/M15 проверяют исполнение, M5 только уточняет.
- Текущая H1-волна обязательно раскладывается на M15-подволны.
- H4/H1/M15 отдельно проверяют уровни, трендовые, каналы, диапазоны,
  треугольники, флаги, вымпелы, клинья/диагонали, двойные вершины/основания,
  H&S, пробой/ретест, false breakout/reentry, BOS/CHOCH и liquidity sweep.
- При позиции: M15 Scout на каждой закрытой свече, глубокий review на
  существенном M15-событии, глубокий review на каждой закрытой H1.
- Волны импульса и коррекции не смешиваются: 1-2-3-4-5, zigzag 5-3-5,
  flat 3-3-5, triangle 3-3-3-3-3, diagonal и W-X-Y проверяются отдельно.

## Стоп и цель

- M15 wave 3: stop anchor — экстремум завершённой wave 1.
- M15 wave 5: stop anchor — экстремум завершённой wave 3.
- Correction C: anchor — экстремум A; Y: anchor — экстремум W.
- Покупка: один tick ниже точного минимума anchor; продажа: один tick выше
  точного максимума. Никакого ATR/spread-запаса нет.
- Если брокер требует большую минимальную дистанцию, применяется только эта
  обязательная дистанция. Уже установленный стоп никогда не ухудшается.
- TP строится Python из подтверждённых raw anchors и допустимой проекции
  Elliott/Fibonacci.

## Строгий FVG

- Геометрию рассчитывает Python по трём закрытым свечам.
- Wick-gap первой и третьей свечи обязан находиться внутри реального тела
  средней направленной импульсной свечи.
- D1 — стратегический, H4 — основной, H1 — входной, M15 — условный; M5 выключен.
- На график проходит только точный кандидат, который Claude признал реально
  значимым для текущей структуры.
- При частичном перекрытии рисуется только незаполненный остаток.
- Касание 50% и отбой от середины имеют отдельные статусы; это ещё не
  полное заполнение. После прохождения середины зона помечается ослабленной.
- Полное заполнение удаляет прямоугольник. Реакция остаётся в истории.
- Свежие свечи обновляют перекрытие уже выбранных зон на вебе без нового FULL.

## Дополнительные исправления

- publisher имеет общий Windows-lock и не запускается в двух экземплярах;
- runtime всегда передаёт отдельный фактический статус торгового шлюза;
- FVG не дублируются в платных payload и распределяются только по нужным TF;
- реальные счета и брокеры не зашиты в код: доступ определяет MT5 и явный
  `config/execution.json`.
