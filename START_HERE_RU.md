# WaveFrame Robot V8.5.2 — начать здесь

Это текущий релиз Windows-робота для MT5. Старые инструкции с номерами V8.4,
V8.5 и V8.5.1 оставлены в репозитории только как история и для установки
V8.5.2 не используются.

## Правильный порядок

1. Прочитать `README.md` — логика таймфреймов, исполнения и FVG.
2. Выполнить `INSTALL_WINDOWS_V8_5_2_RU.md` — чистая установка на Windows
   Server и перенос только личных конфигов.
3. До запуска runner выполнить:

```powershell
.\.venv\Scripts\python.exe -X utf8 .\verify_release.py
.\.venv\Scripts\python.exe -X utf8 .\check_trading_ready.py
```

Ожидаются `PASS`, счёт `DEMO` и `order_send allowed: True`.
`check_trading_ready.py` сам ордеров не отправляет.

## Важные свойства релиза

- `config/execution.json` разрешает настоящий `mt5.order_send()` только на
  DEMO-счёте. Это не dry-run.
- H1 остаётся владельцем структуры; дополнительное решение выполняется после
  промежуточного закрытия M30 в `xx:30`; M15 подтверждает, M5 уточняет вход.
- Во время открытой позиции анализ продолжается на M15 и H1.
- Claude-вызовы выполняются строго последовательно. Refusal, обрыв и неполный
  JSON не считаются успешным анализом и восстанавливаются на том же frozen
  payload.
- FVG отображаются только для D1/H4/H1; полностью перекрытые зоны не рисуются.

Полный список доказанных сценариев находится в
`RELEASE_CHECKS_V8_5_2_RU.md`.
